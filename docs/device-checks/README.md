# Device checks

Manual checks on physical devices, one file per session, named
`<date>-<device>.md`. A session records what was used and what was seen;
[compatibility](../compatibility.md) states what follows from it.

A session file is not edited after the fact. A new check gets a new file,
and compatibility is updated to point to it.

Each session records the device, its OS, the client apps and their
versions, the Natel build with its commit when known, the server, then the
result of each case, including what nobody expected.

[`ios-recheck.md`](ios-recheck.md) is the procedure for the iPhone
recheck.
